# Agent Note: Native Web DSH 会话界面一致性

状态：已实现

[English](2026-10-17-native-web-dsh-session-ui.md) | 中文

## Problem

Native Web 会话页面的标题导航、模式与子会话控件、输入框附件和权限选择、用量摘要以及窄窗口侧栏行为，都与原版 DSH GUI 不同。

## Decision

在所选会话标题下显示“对话”和“轨迹”标签页；轨迹账本以内嵌面板呈现，两个标签页都保留输入框。在标题旁放置可选择的模式标签和直属子会话菜单。计划模式开关留在输入框中，权限选择改为紧凑的本地化菜单，工具栏中的文字图片按钮改为圆形“+”按钮；附件条布局留给 PR-C。根据已加载的会话事件生成弱化的用量行，并且只在输入数据可用时显示对应数值。在窄窗口中，展开的侧栏覆盖主栏，并可通过遮罩或 `collapseNarrow()` 关闭。

当前模型目录没有提供上下文窗口大小，因此用量行不显示上下文百分比。本次不添加粘贴处理（由 PR-C 负责），也不添加缺少后端支持的文件或 `@` 引用操作。

## Alternatives considered

- **保留全屏轨迹对话框：**拒绝，因为它会把账本从会话主内容中分离，并隐藏共用的输入框。
- **继续在输入框中选择模式：**拒绝，因为标题区应标识并控制所选会话的模式。
- **在窄屏网格中保留展开的侧栏：**拒绝，因为在 400px 宽度下会让主栏几乎没有空间。

## Consequences

会话导航仍由控制器管理；标题菜单通过现有控制器选择列表中的直属子会话。用量行只汇总已加载的事件。窄屏侧栏展开时主网格保持轨道宽度，选择会话后会收起抽屉。
