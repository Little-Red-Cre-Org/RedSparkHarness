# Agent Note: 修改编辑器前审核 IDE 代码

[English](2026-10-16-ide-code-review.md) | 中文

Status: implemented

## Problem

自动打开每次生成的回答，无法让用户逐个确认已有代码的修改。

## Decision

现有输入框提交事件在提交已记录提示词前捕获编辑器文本，并选择只读权限。Desktop 扩展将待确认的行修改保留在文档外，只通过编辑器应用用户选中的修改块。已采纳文本与文档版本用于阻止后续采纳覆盖期间发生的编辑。

## Alternatives considered

**先写入再审核。** 撤销被拒绝的方案可能覆盖用户编辑，并且会在同意前触发文件监听器。

**采纳时替换整个文件。** 用户需要只保留选中的修改；独立的行修改块保留其余原文。

## Consequences

右侧栏持有临时预览。每次支持一个完整文件回答；多个代码块需要重新回答。重启扩展会丢弃未采纳预览。只读使用现有 Session 权限预设，请求结束后仍保持选中；普通权限控件仍然适用。无需修改 Session 格式或 agent loop。

## Testing

所属包测试覆盖部分采纳与放弃、全部采纳及过期文档拒绝。现有回答提取测试覆盖已记录并完成的轮次。桌面交互检查在真实编辑器中覆盖相同控件。
