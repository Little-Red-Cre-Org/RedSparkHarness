# Agent Note: IDE AI 侧栏与代码操作

Status: implemented

[English](2026-10-10-ide-ai-sidebar-code-actions.md) | 中文

## Problem

对话占用编辑器标签，传递 AI 代码块需要手动复制粘贴。

## Decision

随应用提供的 Code OSS 扩展持有保留状态的右侧栏 webview。Chat 经现有私有父页面通道转发用户主动触发的插入和预览操作。扩展仅接受当前所选 Session 的操作，修改最近的文本编辑器。插入替换选区或在光标处插入；预览替换选区或整个文档。不可编辑的差异文档提供应用和放弃命令。应用前检查目标文档版本，成功修改进入普通编辑器撤销及自动保存流程。

## Alternatives considered

将对话放进第二个编辑器分组仍占用编辑区域。自动应用模型输出剥夺用户选择。另建 Agent 后端重复 Session 职责，因此继续由现有对话持有会话。

## Consequences

Desktop 在导航 IDE 视图前显示自包含的准备页面。本机工作台文档等待期间持续显示启动状态，不重试服务或改变浏览器安全设置。

IDE 视图关闭 Electron 的后台定时器限速，使编辑器与对话通道在窗口被遮挡后仍能响应。最小化时渲染定时器也会继续运行，以后台功耗换取命令与保存流程的持续推进。

项目操作共用 RSH AI 工具栏。新建项目以独占方式创建空目录，打开已有文件夹使用上游目录选择框。两者经现有文档保存和对话交接流程切换编辑器，不创建第二套工作区或 Session 后端。新建文件使用上游未命名编辑器。

编辑器和对话可以同时可见。IDE 外不提供操作回调，流式生成期间禁用按钮。预览检测期间发生的编辑，不推断补丁或进行多文件合并。右侧栏扩展声明要求上游运行时支持该扩展点。

IDE 会话导航使用当前工作区的会话列表和现有新建会话操作，空白对话也保留入口。内嵌框架省略内层左右侧栏。桌面菜单可打开经过认证的本机浏览器转发连接，访问同一 Host，使会话、记忆和持久化设置由同一后端写入。网页访问随桌面应用关闭，不同步独立启动的 Web profile。

编辑器运行按钮和 AI 运行请求共用 Code OSS Task 执行与可见终端。官方 IDE 模块通过 NativeHost 持有经认证的 MCP 端点；Desktop 组合现有 MCP 客户端，不新增 Cordis 适配器。工具调用方和扩展执行端使用独立凭据。AI 执行要求工作区匹配并在本机确认；输出保留在终端，模型可见结果只报告运行标识和状态。Python 使用配置的 ProcessExecution 参数，不插入 Shell 源码；项目任务仍由上游管理。包内快照覆盖工具结果、运行与信任控制，无需付费模型调用。

MCP 保留每个已初始化的传输，使取消通知到达原先待处理的工具调用。适配器在启动任务前检查取消状态；已取消的确认不能在之后启动运行。真实协议测试同时覆盖此行为、成功派发和执行端不可用的结果。

Java 执行使用已安装 JDK 的编译器，再调用其运行时，包括不支持直接启动源文件的 JDK 8。两个子进程均继承任务终端，支持交互输入和诊断输出。每次编译生成独立临时 class 文件，避免编译失败后执行工作区中的旧字节码；正常结束后删除临时输出。强制终止进程树可能留下临时字节码，交由操作系统清理。Maven 和 Gradle 构建仍使用项目任务，不推测构建命令。

运行按钮按编辑器 URI 类型显示，不按语言隐藏：未命名文档进入保存流程，没有直接运行器的语言提供项目任务入口。C/C++ 使用配置的兼容 GCC 的编译器，每次生成独立可执行文件，避免代码修改后编译失败却运行工作区旧程序。编译器目录只加入任务进程及其子进程的 PATH，保留用户的全局环境，同时允许加载 MinGW 运行库。

Windows IDE 复用上游标题栏，移除重复导航行。Desktop 通过已有工作台协议处理器提供品牌菜单，菜单请求必须来自工作台同源页面。标题栏为原生窗口控件预留空间，交互控件排除在拖动区域之外；返回 RSH 时恢复原窗口标题栏高度。会话导航保留原生选择器及已有操作，并统一控件尺寸。
