# Agent Note: Keep the cold-start intro separate from Host readiness

Status: implemented

[English](2026-10-09-desktop-chixiao-intro.md) | 中文

## 问题

选定的「赤霄初耀」动画需要短暂展示开场，同时不能串行阻塞 Host 启动、遮挡错误或在应用内部重播。渲染器重新加载不能重置进程范围的播放资格。

## 决策

Electron 主进程拥有 available、playing 和 finished 三种片头状态。主窗口的启动页通过受限 IPC 领取播放资格。播放结束或 SKIP 释放展示；只有释放后且 Host 实际就绪才进行导航。错误、窗口关闭和应急恢复都会消耗播放资格。第二次领取会释放前一个渲染器未结束的展示，而不重播。

壳渲染器拥有 5.5 秒计时器、Esc、图片解码和减少动态效果处理。pagehide 时清理计时器与订阅，延迟完成的解码不能重新显示已结束的片头。素材解码失败会释放展示。类型化壳语言字典拥有文案与无障碍名称；品牌名为赤霄初耀，角色名为赤绯。内置素材采用选定的锋刃字体和星轨角标。

本决策补充[立即显示窗口决策](../architecture/2026-09-09-desktop-immediate-window-and-direct-start.zh.md)中就绪后导航的条件。该记录继续负责窗口创建、profile 准备和恢复。Host 与 IDE 的归属不变。

## 考虑过的替代方案

**Host 就绪后立即导航。** 启动较快时会截断已确认的开场；渲染器完成与 Host 就绪是两个独立观测。

**动画结束后才启动 Host。** 这会把整段开场时长加到后端延迟上，并推迟可采取操作的启动错误。

## 后果

启动期间仍可通过 SKIP 与恢复操作交互。应用内没有动画重播或配置入口。壳渲染器快照与生命周期测试覆盖文案、完成、取消、错误、就绪条件和发送方限制。提供的人物设定图仍带有海报文字；选定字标为栅格素材，而非已交付的矢量母版。发布打包和已安装应用的 GUI 仍需单独验证。
