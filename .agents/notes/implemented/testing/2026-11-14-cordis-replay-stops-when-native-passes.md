# Agent Note: Cordis replay stops when the Native replay passes

Status: implemented

English | [中文](2026-11-14-cordis-replay-stops-when-native-passes.zh.md)

## Problem

`snapshots/session/headless.snapshot.ts` selects every `snapshots/session/*/snapshot.yml` whose `profile` is `legacy-headless` and launches it with `dsh --profile legacy-headless`. A Native replay of the same fixture already exists for most of those directories. Deleting the directory removes the fixture that Native test reads. Changing one member of a composition while its `cordis.yml` owner stays selected, or the reverse, makes the runner throw `composition has no cordis.yml owner`.

## Decision

A composition leaves the Cordis runner only as a whole, and only after every Native replay file for its members passes. Leaving means the `profile` field is `headless`. `rsh/Scripts/session-snapshot-corpus.corpus.ts` already allows `headless` under `snapshots/session/`. The fixture directory, `cordis.yml`, and the Native test path stay.

80 directories are `headless`. The `profile` field is the inventory. `ptc-python` left after its replay passed. That replay mounts `@redspark/rsh-experimental-code-runtime-python` only in the isolated scenario. A shipped profile still must not name it. `product-subagent-result-diagnostic` left after its replay passed. That replay uses a stub external driver and Agent-owned jobs; it does not start a product child. The tool config must not pass `provider` unless the driver lists that route field. `subagent-acp-diagnostic` left after its replay passed. The tool name is `subagent_acp`. A stub driver returns the recorded diagnostic with `stopReason: aborted`; the scene does not start an ACP child. `session-query` left after its replay passed. Shipped `headless` provides `sessionQuery` and does not install the query tools. The isolated scenario adds `session-projection` and `tool-session-query`. The recorded call reads seq 10. Native does not log `permission/preset`, `sandbox/mode`, or `approval/policy`, so that request header is seq 7. The replay copies the shared override and changes only that first seq. The shared file still serves the Cordis scenario. The adapter config sets `contextWindow` to `1000000`.

`advanced` stays. `cordis-inspect-jsdoc` owns the composition and exercises `cordis_define`, `cordis_undefine`, and `cordis_inspect_query` from `@redspark/rsh-tool-cordis`, which has no Native entry. The recorded action is to delete `advanced-toolchain`, `advanced-toolchain-runtime`, and `cordis-inspect-jsdoc` when that package goes, not to write a Native replay. See [What still depends on Cordis](../../proposed/architecture/2026-11-10-what-still-depends-on-cordis.md).

`pwsh-tool-turn` stays because this host has no `pwsh` and the Native replay fails with `spawn pwsh ENOENT`. The Cordis runner skips `platform: pwsh` in that case, so the skip is not Native coverage.

These directories have no Native replay file: `advanced-toolchain`, `advanced-toolchain-runtime`, `cordis-inspect-jsdoc`, and `persistent-pwsh-tool-turn`. `persistent-pwsh-tool-turn` still needs re-recording, as [Moving recorded Sessions onto the Native profile](../architecture/2026-11-10-moving-sessions-to-the-native-profile.md) records. `subagent-published-run-failure` stays because the recorded parent result joins the run error and the dispose error, while Native foreground runs call `subagents.run` and title the failure only `subagent run failed` (`rsh/Engine/subagent/tool-subagent/src/native.ts:29`). This cut does not add an environment hook to force the recorded text. `legacy-acp` and `web` stay outside the headless inventory. The SDK runner follows the same leave-as-a-whole rule below.

## Alternatives considered

**Delete the fixture directories once a Native file exists.** Rejected. The Native tests read `snapshots/session/<name>/`, and the corpus gate requires that `snapshot.yml`.

**Skip names inside `headless.snapshot.ts` and leave `profile: legacy-headless`.** Rejected. The corpus gate already checks the profile field. A second skip list would drift from the field that decides selection.

**Move `text-turn` while `skill-load` remains.** Rejected. `text-turn` is the only `default` composition owner. The runner requires that owner among the scenarios it still selects.

## Consequences

The Cordis runner selects 6 `legacy-headless` directories instead of 86. Coverage for the 80 is the Native replay that passed before the field change. A later composition can leave by the same rule. No key was available, so the directories without a Native file were not re-recorded.
