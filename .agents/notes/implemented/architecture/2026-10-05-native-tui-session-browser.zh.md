# Agent Note：原生 TUI 会话浏览器

Status: implemented

[English](2026-10-05-native-tui-session-browser.md) | 中文

## 问题

交互终端需要恢复已存储的对话，同时不重启进程，也不创建另一个 Session writer。

## 决策

选定的持久化 Provider 列出配置工作区内的 Session 标识。终端仅在空闲且没有待回答的人机请求时接受发现与恢复，复用模型控制的取消及排空区间。人机请求取消选择器操作并关闭显示的菜单，不会把菜单选择输入作为回答提交。既有执行器打开选定 Session，由有界历史读取器提供已校验事件。

恢复成功后，控制器才替换选定标识及对话。模型观察从持久事件重建，并清除属于先前对话的元数据。接受恢复后，渲染器清除视图偏移及重试输入。后续用户输入归选定 Session 所有；发现与恢复不提交模型请求。

## 考虑过的替代方案

终端本地 Session 缓存会偏离持久化事实。创建第二个 writer 会绕过执行器的所有权及维护准入。

## 影响

其他工作区的对话不出现在列表中。恢复错误保留当前对话。预设与权限控制、历史滚动及丰富工具面板属于独立能力。
