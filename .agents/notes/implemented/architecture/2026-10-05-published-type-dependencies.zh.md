# Agent Note：发布声明保留经过审查的类型依赖

Status: implemented

[English](2026-10-05-published-type-dependencies.md) | 中文

## 问题

Llm 公共声明引用 Attachment 类型。即使 JavaScript 擦除手写源码中的导入，独立安装的消费者仍需要该依赖。将每个擦除的源码导入分类为仅开发依赖，与发布声明依赖相矛盾。

## 决策

包策略只记录 Llm 到 Attachment 的发布类型关系。源码扫描器复用既有 TypeScript 导入分类器，观察非运行时的包使用。预期 npm 分类将经过审查且实际观察到的类型依赖保留为生产依赖，不虚构 JavaScript 导入，也不改变运行时身份规则。

策略验证拒绝未管理的所有者、未知工作区依赖、重复项，以及缺少源码类型导入观察的登记关系。运行时导出仍遵循既有 peer 身份分类。未登记的类型关系保持既有仅开发依赖处理。

## 后果

Llm manifest 与已安装的 Attachment 依赖保持不变。一个依赖分类回归覆盖源码分类及过期或未知策略拒绝。源码依赖检查证明这一分类；工作区链接的 NodeNext 检查仍是辅助证据，不能证明独立安装。打包安装验收保留既有独立职责。
