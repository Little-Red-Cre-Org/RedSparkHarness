# Agent Note：原生安装作用域组

Status: implemented

[English](2026-10-04-native-installation-scope-groups.md) | 中文

## 问题

彼此不读取服务的独立作用域贡献也可以构成同一个持续执行组合。替换时保留未变请求，会在兄弟模块变化后仍保留该组合的一部分。

## 决策

`NativeContext.groupInstallations()` 将所属安装作用域及其后代注册为共同替换和移除的安装组。取消之前，组扩展与依赖传播先达到固定点。只有全部受影响注册排空、全部受影响资源释放后，才激活已解析的后继安装。组所有权使用精确作用域身份和所属安装的 effect 生命周期；Core 不持有 Agent 或预设类型。

`ResourceOwner.drainRegistrations()` 取消并等待，不释放资源。Host 在按依赖逆序清理之前，对全部受影响所有者应用该屏障。替换过程中的清理失败会停止 Host，不恢复已经释放的前代。

## 影响

Programs 可以将独立注册的贡献绑定到同一持续执行生命周期。安装组替换会取消全部成员，因此资源消费方必须在注册排空期间完成已经接纳的工作。无关安装作用域保留其活动所有者。

## 替代方案

服务依赖推断无法表达独立兄弟贡献。替换整个 Host 会取消无关作用域。作用域组明确指定共同生命周期，同时保留无关安装。

## 验证

实际 Host 测试验证未变计划保留、兄弟替换、后代移除、提前解除注册，以及回调结束后才释放兄弟资源。Core 不选择产品预设；产品选择不属于本次变更。
