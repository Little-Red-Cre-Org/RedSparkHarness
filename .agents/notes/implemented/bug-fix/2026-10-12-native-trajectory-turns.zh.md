# Agent Note：Native Trajectory 保留持久化轮次与计时

Status: implemented

[English](2026-10-12-native-trajectory-turns.md) | 中文

## 问题

Native Trajectory 从当前事件窗口构建记录表。仅投影消息会丢失没有助手消息的失败轮次；缺少持久化步骤计时的助手记录会从前一条可见消息估算耗时。

## 决策

Native 投影会在事件位置和请求记录中保留 `turn/start`、`turn/end`、步骤边界及助手尝试。助手消息计时使用匹配的持久化 `step/start` 时间戳。没有助手消息的失败轮次仍保留为单独轮次行及其失败请求记录。

## 考虑过的替代方案

**根据相邻可见消息推算耗时。** 这样可能让助手跨度早于持久化步骤开始时间，并会随着无关消息而改变。

**只投影用户、助手和 Tool 结果事件。** 这样会丢失保留持久化轮次所需的轮次边界和空失败记录。

## 影响

Native 视图可使用 controller 已加载事件显示空失败轮次和准确的助手步骤开始时间。两个定向回归用例覆盖持久化助手计时，以及失败轮次后接成功轮次的情况。
