# Agent Note: 本机浏览器只读接入

Status: proposed

[English](2026-10-08-local-browser-read-only.md) | 中文

## 问题

零预算工作流需要读取用户授权的本机浏览器标签页。[Web 服务](../../../../rsh/Modules/Official/web/web/README.zh.md)按网址抓取，请求不携带标签页身份或可撤销的浏览器授权。抓取网址不能证明已获准访问用户打开的登录态页面。功能须与正在开发的 IDE 共存，不修改桌面启动，也不另设 Session 写入方。

## 提案

首版保持可独立选择且只读。浏览器拥有的授权标识获准站点与标签页。每次读取都重新核对授权与当前页面身份，再返回有长度限制的标题、网址和可见正文。导航、撤销、断开及超时使待处理读取失效；本范围不含自动重连或扩大权限。扩展从结果中排除表单值、凭据和隐藏内容。

完整实现需要浏览器授权与提取提供方、类型化服务定义及模型工具消费者。工具仅允许读取页面；不支持的操作须在分派时拒绝，包括绕过可见工具列表的调用。在现有工具卡片展示来源网址、标题、截断情况及读取或错误状态。页面正文作为外部不可信数据处理。复用所属应用的工具结果持久化，以及 [Native tools](../../../../rsh/Engine/core/native-tools/README.zh.md) 的策略、审批和取消流程；不单独打开 Session 存储。最终原生 profile 接入须先核对其当前应用消费者。

### 兼容性核查

2026-10-08 核查的[上游桥接清单](https://raw.githubusercontent.com/omdsh-dev/dsh-browser/main/packages/browser/bridge-browser/package.json)版本为 0.0.7，DSH peer 依赖固定为 0.2.0-rc.2。本检出版本的工具包为 0.1.5-rc.2，桥接导出 Cordis 与 Web 客户端入口，并非 Native 安装入口。这些声明不能证明与 RSH 兼容；仅修改版本字符串也不能验证 API。

[上游扩展清单](https://raw.githubusercontent.com/omdsh-dev/dsh-browser/main/extensions/dsh-browser/manifest.json)申请 HTTP/HTTPS 站点权限，并在匹配的框架内安装内容脚本。[工具列表](https://github.com/omdsh-dev/dsh-browser#core-capabilities)包含写入与导航，超出本只读提案范围。仓库采用 [MIT 许可](https://raw.githubusercontent.com/omdsh-dev/dsh-browser/main/LICENSE)，后续复用源码需审查署名。本次变更不包含上游源码或安装器。

### 集成范围

桌面窗口管理、CLI profile 选择、IDE 工作区交接与共享锁文件正在集成期间，浏览器工作不修改这些部分。本机传输须验证对端身份并拒绝非本机调用者；传输选择与浏览器授权生命周期仍需实现和验证。现有 Web 抓取提供方不能替代授权服务。

## 考虑过的替代方案

**原样安装上游桥接。** 其声明的运行时依赖、写入工具和广泛扩展权限不满足 RSH 只读范围。不通过运行安装器试探兼容性。

**把网址抓取当作标签页读取。** 网址抓取没有授权标签页身份，无法执行该标签页授权的撤销。

**新增浏览器对话或执行循环。** 独立循环会重复 Session 与审批的所有权；结果应进入用户当前的 Harness 会话。

## 验收标准

- 本机测试页返回预期标题、网址和正文，不改变页面；结果不含凭据与表单值。
- 未授权站点、撤销授权、页面变化、连接断开和读取超时均返回明确失败。撤销后不得接纳过期结果。
- 点击、输入、提交、删除与导航请求在执行时被拒绝，而非仅在界面隐藏。
- 受支持 profile 的组合在现有 Session 记录来源及成功或失败，并通过无密钥快照重现工具输出。
- 用户可查看连接状态并断开；此后读取失败。Session 输出不包含认证材料。
- 离线测试使用本机测试页，不发起模型请求。模型响应验证独立保留，直至确认可用资源。

## 风险

即使排除表单字段，正文仍可能含个人信息或恶意指令。授权核对须覆盖提取期间的页面变化，而不只检查请求接纳时刻。浏览器扩展生命周期及认证本机传输尚未实现；清单核查不等于已连接浏览器或通过端到端兼容性测试。
