Rename the whole product from DeepSeek Harness to RedSpark Harness

RedSpark Harness started as a fork that kept the upstream identifiers so it could
keep merging from it. That trade-off is over: this is its own application, and
the names are now its own too. From here on the two projects share no identifier
space, which also means this branch can no longer be synced from upstream - the
one cost the owner accepted for it.

## What moved

- Every package: `@deepseek-ai/dsh-*` -> `@redspark/rsh-*` (342 manifests), and the
  vendored framework keeps its own word: `@deepseek-ai/cordis*` -> `@redspark/cordis*`.
- Every environment variable: `DSH_*` -> `RSH_*`.
- Every display name: `DeepSeek Harness` -> `RedSpark Harness`, including the
  installer artifact name.
- `snapshots/`, because tsconfig.host.json type-checks those files with the source.

`.agents/notes/` and `.github/pr-evidence/` are deliberately untouched: they are
dated records of what the repository looked like, and rewriting them would make
them claim something that was not true when they were written.

`rsh/Scripts/rename-to-redspark.ts` carries the mapping and is the only place that
knows the old names. `--check` asserts the post-state, so a future slip fails a
gate instead of drifting.

## Judgements the rename depended on

Four generators and guards stated the old names as their *criteria*, not as data,
so each one silently stopped working the moment the names moved:

- `gen-tsconfig-paths.ts` matched `/^"(@deepseek-ai\/dsh-...)/` to read existing
  aliases, so it saw none and reported 300+ packages unaliased.
- The same file's `mappedPathAliases` used the old scope for native subpaths.
- `install-lefthook.mjs` kept a `dsh-hooks` directory name; `\bDSH_` cannot match
  it, so the guard rejected the leftover path after the rest had moved.
- A bare scope with no subpath (`'@deepseek-ai'`) names the node_modules directory
  itself; a rule that only matched `@deepseek-ai/` left 21 snapshot files behind.

`.d.ts` files are normally build output, but three are authored here and carried
the old names; the two fixtures must agree with the module they declare.

## Verified

    tsc -b tsconfig.host.json        EXIT 0
    tsc -b tsconfig.client.json      EXIT 0
    pnpm run build:lib:host          EXIT 0
    pnpm install                     relinked all 342 packages under the new scope
