# 引用本地文件与对话

[English](file-references.md) | 中文

本指南从已打开 RSH 对话并选好项目工作区开始，介绍 Web 界面和 IDE 内嵌对话现有的 `@` 菜单。这份 Markdown 文件可以在本地离线阅读，不需要模型或网络连接。选择引用和预览本地文本不需要发起模型请求。

## 1. 检查工作区

选择文件前，检查对话输入框上方的工作区名称。相对路径引用属于当前对话的工作目录。两个项目可能有同名文件；发送前先预览所选文件，核对内容。

## 2. 选择文件或文件夹

在对话输入框键入 `@`，菜单先显示**文件与文件夹**，再显示**对话**。输入部分文件名或目录路径缩小候选范围，然后选择对应行。选中的引用会以简短标签出现在草稿中。

路径包含空格时，可直接选择菜单项，或手动输入带引号的引用，例如 `@"course work/中文 作业.txt"`。手动输入完整路径时保留结尾引号。复制引用会保留路径表示；仅凭标签显示的文件名不能判断它属于哪个目录。

选择文件夹行会引用文件夹本身。按 Tab 或点击该行的浏览按钮，可以进入目录继续选择子项。引用文件夹不会把里面的所有文件都作为附件发送。

刚创建的文件没有出现在模糊搜索中时，可输入它所在的目录路径，例如 `@src/`；目录名包含空格时使用 `@"course work/`。直接目录查询会读取对应目录；模糊候选使用索引，可能落后于外部文件变更。详见[本地候选发现限制](../../../Engine/context/file-reference-local/README.zh.md#known-limitations-and-deferred-work)。

## 3. 发送前预览

点击草稿中的文件引用打开预览，核对文件名和正文是否符合预期。**重新读取文件**会再次读取当前内容。选择后被删除的文件，在重新读取时会报错；先前的选择不会保存一份独立的文件内容副本。

选择和预览不代表模型已经读过文件。文件引用在待发送消息中表示路径，智能体需要通过文件工具读取正文。详见[文件引用行为](../../../Engine/context/file-reference/README.zh.md)。

## 4. 引用其他对话

键入 `@`，从**对话**分组选择一项，发送前核对标签及工作区信息。即使其他对话使用相同标题，引用仍保留所选对话的身份。以 `@"` 开头的带引号搜索只显示文件。

消息开始处理时，宿主会校验对话引用，并捕获有大小限制的只读上下文快照。来源对话后续变化不会改写已捕获的内容。引用准备可能失败，有大小限制的快照也不保证包含全部历史。详见[对话引用行为](../../../Engine/context/session-reference/README.zh.md)。

## 5. 核对结果与费用

发送前，在[模型设置](providers.zh.md)中检查所选模型及其提供方的计费条件。阅读本地指南、选择引用和预览本地文件不会购买订阅或调用模型。发送消息可能产生模型费用，包括引用上下文及后续工具结果处理。免费编辑器或扩展不等于免费模型额度。

发送后，在原对话中查看文件读取结果和模型回复。出现引用标签本身不能证明读取成功。没有已确认的免费额度或本地模型时，停留在选择和预览步骤；模型响应仍属未验证。

## 常见问题

| 看到的情况 | 检查方法 |
|---|---|
| 没有匹配文件 | 核对当前对话的工作区、拼写及目录路径。候选发现有数量限制，也会排除配置中指定的目录。 |
| 菜单缺少文件或对话分组 | 一个候选来源失败时，另一个仍可使用。仅凭分组缺失不能断定文件或对话不存在。 |
| 预览提示读取失败 | 检查文件是否仍存在、是否可读，再重新读取。不要把之前显示的预览当作文件当前内容。 |
| 模型没有回复 | 查看对话中的错误及模型配置。选择或预览成功不代表凭据、额度或服务可用性已经验证。 |
