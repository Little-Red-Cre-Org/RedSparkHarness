# 不增加服务费用地引用本地文件

[English](file-references.md) | 中文

## 概述

使用现有 Web UI 选择工作区文件，并在发送任务前核对路径。本指南是本地 Markdown 文件，阅读时无需模型、订阅或网络连接。这里介绍 Harness 会话输入框；独立 IDE 编辑器的操作入口可能不同。

<a id="choose-the-workspace"></a>
## 选择工作区

从已经运行的 Web UI 开始，按[选择工作区](index.zh.md)操作，选中作业或项目所在目录。添加引用前核对会话所属工作区，尤其注意不同项目中的同名文件。

<a id="select-and-inspect-a-file"></a>
## 选择并查看文件

1. 在会话输入框键入 `@`，再输入部分文件名或相对路径。文件与会话候选共用这个菜单；引用文件时选择文件行。
2. 选择目标文件。`作业/实验报告.md` 对应 `@作业/实验报告.md`；含空格路径需要引号，例如 `@"课程 资料/实验 报告.md"`。通过候选项选择时会自动处理引号。
3. 进入文件夹内部时，使用行尾箭头或 Tab。直接选择文件夹行会插入文件夹引用，不会附加其中所有文件。
4. 点击已插入的文件引用，在右侧栏查看当前内容。发送前核对路径与内容。只看到引用标签，不代表模型已经读过文件。

可以在选择并预览文件后停止。发送任务是另一步操作，可能调用已配置模型。文件引用标识的是路径，不会冻结一份文件内容副本。

<a id="check-results-and-failures"></a>
## 核对结果与错误

发送已授权的任务后，在同一会话查看工具结果和回复。对于生成的文件，先检查工作区中的实际文件，再判断回复描述是否可信。

| 现象 | 检查内容 |
|---|---|
| 没有文件候选 | 确认工作区，并尝试输入相对目录路径。发现服务不可用或失败也会出现空菜单，不能据此断定文件不存在。 |
| 搜索不到某个文件 | 检查目录、拼写与访问权限。发现过程会排除已配置的目录，也不会跟随目录符号链接。 |
| 预览或读取失败 | 核对错误中的路径与原因，再检查文件是否仍存在且可读。不要用另一个同名文件替代。 |
| 发送被拒绝 | 阅读输入框附近的错误，重试前检查恢复的草稿。不要把被拒绝的提交视为已完成模型轮次。 |

<a id="keep-model-costs-separate"></a>
## 单独核算模型费用

阅读指南和浏览本地文件候选本身不会请求模型推理。发送任务可能把引用内容交给所选提供方，并消耗其额度。插件可用不代表模型免费。发送前确认提供方与账户额度；没有确认可用资源时，仅完成本地选择与预览。连接设置见[模型配置](providers.zh.md)。

<a id="dev-note"></a>
## 开发备注

定向测试覆盖本地发现、中文与含空格路径、引用选择、序列化、预览路由及提交被拒绝的情况。真实桌面交互和模型响应须由运行界面的集成人员另行验收；这些测试没有验证独立 IDE 工作台。
