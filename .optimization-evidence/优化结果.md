## 实际修改

| 功能 | 结果 | 代码所在工作目录 |
|---|---|---|
| 会话引用 | 初始测量一次完整 JSON，删除和截短时按精确序列化字节差更新，避免反复编码剩余对话 | `E:/redsparkHarness/RedSparkHarness-code-optimization` |
| 文件补全 | 每次查询只做一次大小写归一化，不再为每个候选重复转换 | 同上 |
| 浏览器只读 | 验证帧头后分配一次正文缓冲区，按偏移写入分片，保留 1 MiB 上限与错误处理 | `E:/redsparkHarness/RedSparkHarness-zero-budget-next` |
| 图片追问 | 按历史顺序查找原图，找到第一个匹配后停止后续投影；仍读取完整历史 | `E:/redsparkHarness/RedSparkHarness-image-understanding` |
| 工具组 | 保留逐请求读取持久授权并与当前配置求交，未添加可能失效的权限缓存 | 只读审查 `RedSparkHarness-tool-groups` |
| IDE | 保留启动、返回、保存、关闭各自的异步流程，未发现值得承担回归风险的低风险删除点 | 只读审查 `RedSparkHarness-ide-integration` |

## 局部性能测量

Node v24.15.0，同一机器，每项取 3 次中位数。修改前后返回结果逐项深度相等；脚本为 `measure.mjs`，原始结果为 `performance.json`。

| 合成场景 | 修改前 | 修改后 |
|---|---:|---:|
| 100 条消息裁剪到 1024 字节 | 3.783 ms | 0.277 ms |
| 500 条消息裁剪到 1024 字节 | 127.733 ms | 1.578 ms |
| 1500 条消息裁剪到 1024 字节 | 1244.087 ms | 5.664 ms |
| 140011 字节 JSON，按 1024 字节分片接收 | 4.322 ms | 0.360 ms |
| 140011 字节 JSON，按 32 字节分片接收 | 166.239 ms | 1.170 ms |

以上仅代表局部合成处理场景，不代表磁盘读取、模型响应、Chrome 或整个桌面程序同比提速。会话裁剪仍有数组查找与删除成本。
