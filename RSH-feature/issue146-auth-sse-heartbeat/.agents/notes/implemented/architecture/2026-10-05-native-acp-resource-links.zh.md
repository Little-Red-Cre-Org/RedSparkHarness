# Agent Note：原生 ACP 资源链接

Status: implemented

[English](2026-10-05-native-acp-resource-links.md) | 中文

## 问题

标准 ACP 资源链接在文本和图片旁携带引用。拒绝这些引用会阻止原生客户端提交兼容承载层支持的提示。

## 决策

原生 ACP 将标准资源链接转换为兼容承载层的方括号文本，名称与 URI 按 JSON 加引号。相邻文本合并，图片位置不变。执行器在模型准入之前记录完整的已转换用户消息，恢复历史因此包含相同引用。承载层不抓取链接资源，也不接受嵌入资源。

## 考虑过的替代方案

抓取链接资源会增加未请求的文件系统或网络操作，以及持久化准入要求。新增内容类型会改变模型输入语义，而非保留既有文本引用。

## 影响

链接不需要额外 Provider。图片准备保持根执行所有权与取消机制。协议元数据不进入模型输入。上下文用量仍待原生 token-meter 能力提供测量占用与容量，承载层不发布虚构 token 数。兼容默认值保持不变。
