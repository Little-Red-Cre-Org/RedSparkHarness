# Agent Note: RedSpark 产品标识

Status: implemented

[English](2026-09-13-redspark-brand.md) | 中文

## Problem

本分支需要独立的产品标识，同时保留有用的上游集成路径和来源说明。

## Decision

RedSpark 是组织和未来模型的名称；RedSpark Harness（SPH）是平台名称。共享客户端主题别名和品牌标记覆盖 Web 与桌面端。欢迎页使用基于用户设定图制作的透明四帧赤绯精灵图。CSS 实现呼吸、眨眼和挥手；本地 React 状态处理打招呼与暂停按钮，不发送模型请求。默认遵循减少动态效果偏好，用户可为当前欢迎页明确启用动效。服务商名称继续标识实际 API 服务。README 明确标注保留的上游资源。

## Alternatives considered

**全局替换标识符：** 修改包名、凭据引用和 profile 路径会破坏既有配置，也不会改善视觉标识。这些标识保留上游拼写。

**在对话中持续展示角色：** 长期装饰会争夺代码和消息的注意力。角色图限定在空白欢迎页，并在低高度或窄窗口中隐藏。

## Consequences

RedSpark 拥有产品展示层，本分支继续保留上游许可证声明与运行时兼容性。简化火焰星芒替代鲸鱼，用户提供的完整设计图继续作为设计参考。这不添加 RedSpark 模型服务商，也不改变模型请求。
